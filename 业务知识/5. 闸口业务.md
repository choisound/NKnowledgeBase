# 闸口业务

码头闸口是陆运和海运的衔接点，也是进出港口的“咽喉”要道。它不仅是划分码头内外责任的物理边界，更是集装箱进行交接、单据处理和信息记录的核心业务部门。闸口通过一系列标准化流程，确保集装箱运输的安全、高效与可追溯。下来介绍码头闸口主要涉及到四个业务角色和两个流程，此外，介绍现阶段码头闸口智能化方面的创新模式。

## 五个业务角色

闸口流程主要涉及到船公司、货主、船代、拖车公司以及码头闸口四个角色，每个角色各司其职，保障了货物安全有序的运输。

### 船公司 (船公司)

货物承运方，拥有集装箱，制定运输计划。作为海运环节的实际承运人，主要负责：

* ​**提供运力​**：发布船期，提供船舶舱位，确保海上运输能力。
* **​发放与回收集装箱**​：管理集装箱的周转，负责空箱的发放和重箱的回收。
* **制作并传输舱单​**：在船舶离港后，向海关传输清洁舱单，这是后续报关、提货的重要依据。

### 货主 (发货人/收货人)

作为货物的所有者和整个运输需求的发起方，货物所有权人，发起订舱，支付运费，主要职责包括：

* **​准备货物与单证​**：负责准备符合要求的货物，并备齐商业发票、装箱单、合同等全套贸易单证。
* **委托与付款​**：委托可靠的货代，并根据协议支付运费及相关费用。
* **​结算货款**​：最终凭货代转交的海运提单等凭证，向银行办理结汇或付款。

### 货代 (货运代理)

作为连接各方的核心协调者和专业服务提供方，处理船舶与码头的本地事务，其工作贯穿始终：

* **​订舱​**：代表货主向船公司申请舱位。
* **安排运输​**：协调车队进行提箱、装货、将重箱运送至码头等内陆运输环节。
* **代办报关**​：通常委托专业的报关行向海关办理进出口申报手续。
* **​处理异常**​：如遇海关查验，负责与码头、海关沟通，安排后续处理。

### 拖车公司

作为工厂到码头闸口之间集装箱运输的唯一渠道，其工作主要包括：

* **提取空箱​**：凭货代提供的提箱单证（如EIR），驾驶空车头前往码头闸口或船公司指定的堆场办理提空箱手续。
* **​装货与运送**​：将空箱运至货主指定地点完成装货并施加铅封，然后将重箱运至码头闸口​。

### 码头闸口 (Container Terminal Gate)

作为集装箱在陆运和海运之间转换的核心枢纽，责任分界点，执行交接检查，协调各方作业，其作业非常关键：

* **​单证核对**​：闸口系统会自动识别并核对提箱凭证上的所有信息，如箱号、船名、航次、箱型尺寸等，确保信息匹配才会放行。
* **箱体验残​**：验箱员会仔细检查集装箱的外观状况，如有无破损、变形等，并将检查结果录入系统，明确责任划分。
* **指定场位​**：核对无误后，系统会为集装箱分配一个在堆场内的具体存放位置，并打印入场凭证。
* **进出闸管理​**：通过集成的地磅系统，自动采集集装箱的实际重量，并与预录入信息比对，是安全运输的重要一环。

## 两个业务流程

码头闸口主要涉及到两个核心作业流程，提空返重箱的出口流程以及提重返空的进口流程。

### 集装箱出口流程

从工厂到船舶的提空返重出口重箱流程，出口流程始于货主的货物，终于集装箱被装载上船。这是一个典型的“重箱进场”过程，各角色紧密协作，确保货物合规、安全地离开国门。

1. **安排订舱 (货主)**
货主通过货代向船公司或其代理提交订舱申请，确定船期、航线及费用。船公司审核后发放 设备交接单 (EIR) ，授权拖车提箱。
2. **提取空箱 (拖车公司)**
拖车公司凭EIR到码头堆场提取空箱。拖车在到港前需要根据线上平台等途径对码头进行预约，预约后拖车按照预约时间进闸时，闸口箱检员要核对车号与EIR单是否相符，检查车况；闸口文员则会录入拖车空车重量，并安排提箱的场位；在此环节的核心任务是**验箱** ，核对箱号、铅封完整性，并记录箱体状况。部分码头当集装箱出现残损的时候还可能进行二次进闸的换箱操作，
3. **装箱与进场 (货主/拖车)**
货主在工厂或码头指定堆场装箱并施加铅封。拖车公司凭 场站收据 等单证，将已装货的重箱运至码头。闸口再次验箱，确认铅封完好，并将箱体信息录入系统，若有异常则填写报告单。此时会过磅称重，求出重箱重量，并安排重箱在堆场的箱位。
4. **报关与放行 (货主/船代)**
货主委托报关行向海关申报。船代在此环节扮演协调角色，将海关放行信息传递给码头，为后续装船做准备。
5. **装船 (船公司/码头)**
船公司根据装船计划，码头操作部门将集装箱吊装上船。至此，出口流程在码头端完成。

### 集装箱进口流程

从船舶到工厂的提重返空的进口流程与出口相反，始于船舶抵达，终于货物送达货主。这是一个“重箱出场”的过程，各角色同样各司其职，确保货物顺利进入国内市场。

1. **船舶抵港与申报 (船公司/船代)**
船舶抵港前，船公司通过船代向海关提交进口舱单等资料进行申报。船代负责协调泊位、装卸等本地事务。
2. **卸船与堆存 (船公司/码头)**
船舶靠泊后，码头操作部门将集装箱卸船并按箱主、箱型分类堆存。船公司负责确认卸船数量。
3. **货主提货 (货主/拖车)**
货主凭正本提单换取提货单（DO），并委托拖车公司办理提柜。码头闸口在此环节的核心任务是 交箱 ，核对提货单信息，确认铅封完好后完成交接。
4. **运输与拆箱 (货主)**
拖车公司将重箱运至货主工厂。货主拆箱后，将空箱返还至码头堆场或船公司指定地点。

### 码头闸口创新模式

现代码头闸口正经历一场深刻的智能化变革，从传统的“人海战术”和纸质单据，向“无人化、自动化、数字化”的方向演进。其核心目标是通过先进的技术手段，实现对进出港口的集装箱运输车辆进行高效、准确、安全的自动化管理，从而大幅提升港口的吞吐能力和作业效率。

1. 自动识别与数据采集系统
这是智能闸口的“感知器官”，负责在车辆无需完全停车的情况下，快速、准确地采集所有必要信息。

* **集装箱号自动识别**
通过安装在闸口的 工业级高清摄像机 ，利用深度学习算法对集装箱进行图像识别，自动读取箱号、ISO箱型代码、箱门朝向等信息。系统具备强光抑制和低照度增强功能，确保全天候稳定运行。  

* **车牌与车辆信息识别**
采用 RFID电子车牌 或 视频车牌识别 技术。RFID标签内存储车辆唯一ID、车牌号、所属公司等信息，车辆通过时可被自动读取，识别率高达99%以上，从根本上杜绝了套牌车现象。

2. 箱体定损与验残系统
该系统通过高清摄像头自动抓拍集装箱的六个面（尤其是前后左右大侧面），生成清晰图片供后台系统或验残员远程审核。这不仅消除了人工攀爬检查的安全隐患，还实现了验残过程的标准化和可追溯。
3. 电子地磅衡重系统
集成在闸口通道中的高精度地磅，可自动称量通过车辆的重量。系统会将称重数据与车辆信息关联，实时判断是否超载，为后续作业和安全管控提供依据。 

4. 自动控制与放行系统
作为闸口的“执行大脑”，该系统集成了电气控制装置、传感器和控制器。它根据前端采集和识别的所有数据，进行逻辑判断和决策，自动控制信号灯和道闸臂的升降，实现符合条件车辆的无人化自动放行。
